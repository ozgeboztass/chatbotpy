# Python Pro Level Instructor Exam System

This project is an exam system developed for Python instructors. It is built using Flask and SQLAlchemy.

## Features

- 5 different Python topic exams
- User authentication
- Exam result tracking
- High score display
- Responsive design

## Installation

1. Clone the project:
```bash
git clone [repo-url]
cd [repo-name]
```

2. Create and activate virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate  # Windows
```

3. Install required packages:
```bash
pip install -r requirements.txt
```

4. Create .env file:
```bash
cp .env.example .env
```

5. Run the application:
```bash
python run.py
```

## Technologies Used

- Flask
- SQLAlchemy
- Flask-Login
- Flask-WTF
- SQLite
